# Skill 索引

Skill 正文在公開庫 [omni-skills](https://github.com/Fallins/omni-skills)，經 `install-skills.sh` symlink 到各工具掃描目錄。這裡只列何時用。

| Skill | 何時 |
|---|---|
| `enroll` | 初始化工作區骨架，或把目前 git 納管進 work／personal |
| `gs-setup` | 只建／補 `issue-tracker.md` 工作區 |
| `gs-grill-with-docs` | 對齊需求並寫 CONTEXT／ADR |
| `gs-to-spec`／`gs-to-tickets`／`gs-implement` | spec → tickets → TDD |
| `gs-code-review`／`gs-handoff`／`gs-diagnosing-bugs` | review、交接、難除 bug |
| `eli5` | 用 HTML 視覺解釋現有程式怎麼跑 |
